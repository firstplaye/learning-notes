# 1.为什么需要自增列  
主键用于唯一识别一行数据。如果每次插入数据都手动指定 ID，容易重复或混乱。自增列可以让数据库自动生成 ID。 

## 1.创建自增主列
MySQL:  
`主键列名 BIGINT PRIMARY KEY AUTO_INCREMENT,`
Oracle:
`主键列名 NUMBER(19) GENERATED ALWAYS AS IDENTITY PRIMARY KEY,`默认自增：不手动指定 ID  

`主键列名 NUMBER(19) GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,`可以手动指定 ID：BY DEFAULT  
Oracle Sequence 旧写法:  
`CREATE SEQUENCE 序列名 START WITH 起始值 INCREMENT BY 增长值;`  
PostgreSQL:  
`主键列名 BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,`
SERIAL / BIGSERIAL 旧写法:  
`id BIGSERIAL PRIMARY KEY`
SQL Server:  
`主键列名 BIGINT IDENTITY(起始值,增长值) PRIMARY KEY,`

# 2.索引是什么
索引用于提高查询速度。

## 1.创建索引
`CREATE INDEX 索引名 ON 表名 (列名);`

## 2.索引为什么不是越多越好
索引需要占用存储空间。新增、修改、删除数据时，索引也要更新。无用索引会增加维护成本。
