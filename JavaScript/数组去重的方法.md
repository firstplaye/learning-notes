# JavaScript 数组去重方法详解

数组去重，就是**删除数组中重复的元素，只保留一份**。

例如：

```javascript
const arr = [1, 2, 2, 3, 3, 4, 1];

// 去重后
[1, 2, 3, 4]
```

JavaScript 中有多种去重方式，主要包括：

1. `Set` + 展开运算符
2. `filter()` + `indexOf()`
3. `for` + `includes()`
4. `reduce()` + `includes()`
5. `for` + `Set`
6. `Map` 去重
7. 对象数组去重
8. 多个数组合并后去重

---

## 一、使用 `Set` + 展开运算符

> 推荐：简单数组去重

```javascript
const arr = [1, 2, 2, 3, 3, 4, 1];

const result = [...new Set(arr)];

console.log(result);
// [1, 2, 3, 4]
```

### 1. `Set` 是什么？

`Set` 是 JavaScript 中的一种数据结构，它的特点是**同一个值只能保存一次**。

```javascript
const set = new Set([1, 2, 2, 3, 3]);

console.log(set);
// Set(3) {1, 2, 3}
```

当重复值进入 `Set` 时，只会保留一份。

### 2. 为什么需要 `...`？

`Set` 不是数组，不能直接当作普通数组使用。

```javascript
const set = new Set([1, 2, 3]);

const result = [...set];

console.log(result);
// [1, 2, 3]
```

`...set` 会把 `Set` 中的元素展开，再由 `[]` 创建新数组。

### 3. 执行过程

```javascript
const arr = [1, 2, 2, 3];

const set = new Set(arr);
// Set {1, 2, 3}

const result = [...set];
// [1, 2, 3]
```

**特点：**

- 代码简洁。
- 保留元素第一次出现的顺序。
- 适用于数字、字符串等基本类型。
- 对对象按引用去重，而不是按对象内容去重。

---

## 二、使用 `filter()` + `indexOf()`

这种方法适合练习数组回调方法和索引。

```javascript
const arr = [1, 2, 2, 3, 3, 4];

const result = arr.filter((item, index) => {
    return arr.indexOf(item) === index;
});

console.log(result);
// [1, 2, 3, 4]
```

### 1. `indexOf()` 的作用

`indexOf()` 用于查找某个元素**第一次出现的位置**。

```javascript
const arr = [10, 20, 20, 30];

console.log(arr.indexOf(20)); // 1
console.log(arr.indexOf(30)); // 3
console.log(arr.indexOf(99)); // -1
```

### 2. `filter()` 的作用

`filter()` 会遍历数组，只有回调函数返回 `true` 的元素才会被保留。

```javascript
const arr = [10, 20, 30];

const result = arr.filter(item => item > 10);

console.log(result);
// [20, 30]
```

### 3. 去重的关键原理

```javascript
arr.filter((item, index) => {
    return arr.indexOf(item) === index;
});
```

这里有两个值：

- `item`：当前元素。
- `index`：当前元素在数组中的索引。

**判断条件：**

`arr.indexOf(item) === index`

只有当前元素的索引与它第一次出现的位置相同，才保留它。

例如：

| 当前元素 | 当前索引 | `indexOf(item)` | 是否保留 |
|---|---:|---:|---|
| 1 | 0 | 0 | 是 |
| 2 | 1 | 1 | 是 |
| 2 | 2 | 1 | 否 |
| 3 | 3 | 3 | 是 |

### 4. 特点

- 返回一个新数组，不修改原数组。
- 逻辑直观，适合理解回调函数。
- 对较大的数组效率通常不如 `Set`。
- 对 `NaN` 的处理与 `Set` 不同。

---

## 三、使用 `for` + `includes()`

这种方法通过循环遍历数组，判断新数组中是否已经存在当前元素。

```javascript
const arr = [1, 2, 2, 3, 3, 4];

const result = [];

for (let i = 0; i < arr.length; i++) {
    if (!result.includes(arr[i])) {
        result.push(arr[i]);
    }
}

console.log(result);
// [1, 2, 3, 4]
```

### 1. `includes()` 是什么？

`includes()` 用于判断数组中是否包含某个元素。

```javascript
const arr = [1, 2, 3];

console.log(arr.includes(2)); // true
console.log(arr.includes(5)); // false
```

### 2. 去重原理

```javascript
if (!result.includes(arr[i])) {
    result.push(arr[i]);
}
```

这段代码可以拆成三个步骤：

1. `arr[i]` 获取当前元素。
2. `result.includes(arr[i])` 判断结果数组中是否已经有这个元素。
3. 如果没有，就用 `push()` 添加到结果数组。

### 3. 执行过程

假设原数组是：

```javascript
const arr = [1, 2, 2, 3];
```

| 当前元素 | `result.includes()` | 操作 | 结果数组 |
|---|---|---|---|
| 1 | `false` | 添加 | `[1]` |
| 2 | `false` | 添加 | `[1, 2]` |
| 2 | `true` | 跳过 | `[1, 2]` |
| 3 | `false` | 添加 | `[1, 2, 3]` |

### 4. 特点

- 逻辑容易理解。
- 可以处理 `NaN`，因为 `includes()` 能正确判断 `NaN`。
- 不会修改原数组。
- 数组较大时，重复查找可能带来较高的时间开销。

---

## 四、使用 `reduce()` + `includes()`

`reduce()` 可以把数组逐步累积成一个结果，这里用它来累积去重后的数组。

```javascript
const arr = [1, 2, 2, 3, 3, 4];

const result = arr.reduce((acc, item) => {
    if (!acc.includes(item)) {
        acc.push(item);
    }

    return acc;
}, []);

console.log(result);
// [1, 2, 3, 4]
```

### 1. `reduce()` 的基本结构

```javascript
arr.reduce((acc, item) => {
    // 处理当前元素
    return acc;
}, []);
```

这里：

| 参数 | 含义 |
|---|---|
| `acc` | 累积器，保存当前的去重结果 |
| `item` | 当前遍历到的元素 |
| `[]` | 初始累积值，也就是空数组 |

### 2. 去重过程

以 `[1, 2, 2, 3]` 为例：

- 第一次：`acc = []`，加入 `1`。
- 第二次：`acc = [1]`，加入 `2`。
- 第三次：`acc = [1, 2]`，发现 `2` 已存在，跳过。
- 第四次：`acc = [1, 2]`，加入 `3`。

最终结果：

```javascript
[1, 2, 3]
```

### 3. 为什么必须 `return acc`？

因为 `reduce()` 需要通过返回值，把当前累积结果传递给下一轮。

如果忘记返回 `acc`，下一轮的累积器就可能变成 `undefined`，导致报错。

### 4. 特点

- 可以练习累积器的使用。
- 返回新数组。
- 逻辑比 `for` 循环稍复杂。
- 这种写法不一定比 `Set` 更高效。

## 五、使用 `for` + `Set`

这种方法和第一种方法使用相同的去重原理，但手动遍历数组。

```javascript
const arr = [1, 2, 2, 3, 3, 4];

const set = new Set();

for (const item of arr) {
    set.add(item);
}

const result = [...set];

console.log(result);
// [1, 2, 3, 4]
```

### 关键方法

- `new Set()`：创建一个空集合。
- `set.add(item)`：添加元素，重复值不会重复保存。
- `[...set]`：将集合转换成数组。

这种写法适合想要明确控制遍历过程的情况，也方便在循环里增加其他判断逻辑。

## 六、使用 `Map` 去重

`Map` 是一种键值对数据结构。可以利用它的键不重复这一特点实现去重。

```javascript
const arr = [1, 2, 2, 3, 3, 4];

const map = new Map();

for (const item of arr) {
    map.set(item, item);
}

const result = [...map.keys()];

console.log(result);
// [1, 2, 3, 4]
```

### 原理

```javascript
map.set(item, item);
```

如果同一个键重复设置，`Map` 中仍然只有一个对应的键。

最后：

```javascript
[...map.keys()]
```

获取所有键并转换为数组。

### 特点

- 适合需要同时保存额外信息的场景。
- 单纯数组去重时，通常直接使用 `Set` 更简单。
- 如果键相同，后续设置会覆盖之前的值。

## 七、对象数组去重

前面的方法主要针对数字、字符串等基本类型。实际开发中，经常需要对对象数组去重。

例如，有一个员工列表：

```javascript
const employees = [
    { id: 1, name: "小明" },
    { id: 2, name: "小红" },
    { id: 1, name: "小明" },
    { id: 3, name: "小刚" }
];
```

希望根据 `id` 去重，保留每个员工的第一条记录。

### 方法 1：使用 `filter()` + `findIndex()`

```javascript
const result = employees.filter((item, index) => {
    return employees.findIndex(employee => {
        return employee.id === item.id;
    }) === index;
});

console.log(result);
```

结果：

```javascript
[
    { id: 1, name: "小明" },
    { id: 2, name: "小红" },
    { id: 3, name: "小刚" }
]
```

**原理：** `findIndex()` 找到相同 `id` 第一次出现的位置，只有第一次出现的对象才会被保留。

### 方法 2：使用 `Map`，根据 `id` 去重

```javascript
const map = new Map();

for (const employee of employees) {
    if (!map.has(employee.id)) {
        map.set(employee.id, employee);
    }
}

const result = [...map.values()];

console.log(result);
```

这里：

- `map.has(employee.id)`：判断该员工 ID 是否已经存在。
- `map.set(employee.id, employee)`：保存员工对象。
- `map.values()`：获取所有员工对象。

这种写法会保留每个 `id` 第一次出现的对象。

### 方法 3：使用 `Set` 保存已出现的 ID

```javascript
const seen = new Set();

const result = employees.filter(employee => {
    if (seen.has(employee.id)) {
        return false;
    }

    seen.add(employee.id);
    return true;
});

console.log(result);
```

这种写法非常适合根据某个字段去重，例如员工编号、商品 ID、用户 ID。

## 八、多个数组合并后去重

如果有多个数组，希望合并后去重，可以先使用展开运算符合并，再通过 `Set` 去重。

```javascript
const arr1 = [1, 2, 3];
const arr2 = [2, 3, 4];
const arr3 = [3, 4, 5];

const result = [...new Set([...arr1, ...arr2, ...arr3])];

console.log(result);
// [1, 2, 3, 4, 5]
```

### 执行过程

```javascript
// 第一步：合并数组
[...arr1, ...arr2, ...arr3];
// [1, 2, 3, 2, 3, 4, 3, 4, 5]

// 第二步：Set 去重
new Set([...arr1, ...arr2, ...arr3]);

// 第三步：转换回数组
[...new Set([...arr1, ...arr2, ...arr3])];
// [1, 2, 3, 4, 5]
```

## 九、几种方法的对比

| 方法 | 适用场景 | 主要特点 |
|---|---|---|
| `Set` + 展开运算符 | 基本类型数组 | 简洁、常用 |
| `filter()` + `indexOf()` | 基本类型数组 | 适合理解索引 |
| `for` + `includes()` | 基本类型数组 | 逻辑直观 |
| `reduce()` + `includes()` | 基本类型数组 | 练习累积器 |
| `for` + `Set` | 需要手动控制遍历 | 方便增加逻辑 |
| `Map` | 根据键去重 | 适合保存键值关系 |
| `filter()` + `findIndex()` | 对象数组 | 根据字段筛选 |
| `Set` + 对象属性 | 对象数组 | 根据 ID 去重 |

---

## 十、几个容易踩的坑

### 1. `Set` 无法按对象内容去重

```javascript
const arr = [
    { id: 1 },
    { id: 1 }
];

console.log([...new Set(arr)]);
```

结果仍然有两个对象。

因为两个对象虽然内容相同，但它们是不同的对象引用。

### 2. `indexOf()` 无法正确查找 `NaN`

```javascript
const arr = [NaN, NaN, 1];

console.log(arr.indexOf(NaN)); // -1
```

因此使用 `filter() + indexOf()` 时，`NaN` 会被全部过滤掉。若需要保留一个 `NaN`，可以使用 `Set` 或 `includes()` 的方案。

### 3. 去重不一定要修改原数组

上面这些写法大多返回一个新数组，不会直接改变原数组。使用时可以通过 `const result = ...` 保存结果。

---

## 总结

如果你正在学习 JavaScript，建议按照下面的顺序掌握：

1. **先掌握 `Set` + 展开运算符**，理解最常见的去重方式。
2. 再掌握 `filter()` + `indexOf()`，理解索引和回调函数。
3. 接着练习 `for` + `includes()`，理解循环与条件判断。
4. 最后学习对象数组去重，重点掌握根据 `id` 去重。

一句话记忆：**普通数组去重用 `Set`，对象数组去重通常根据唯一字段（如 `id`）判断。**
