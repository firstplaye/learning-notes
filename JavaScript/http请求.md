# 1.JavaScript 中的 CORS 是什么？
CORS（Cross-Origin Resource Sharing，跨源资源共享） 是一种浏览器安全机制，用于控制网页能否访问不同源的服务器资源。CORS 主要用于解决前端跨域请求的问题。

## 1.什么是跨域？
首先要理解什么是「同源」和「跨源」。一个 URL 由协议、域名和端口等部分组成。  

例如：
```
前端：http://localhost:5173
后端：http://localhost:8080
```
虽然这两个地址的域名都是 localhost，但端口不同，因此属于不同源。  

浏览器判断是否同源，需要同时满足：协议相同,域名相同,端口相同。**只要其中一个不同，就属于跨源。**
