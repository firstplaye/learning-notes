## 工具

笔记里的 Vue 示例可以直接在浏览器里跑起来：

```bash
node tools/vue-playground.mjs vue/快速入门.md --write
```

点开就是 <https://play.vuejs.org> 并已载入这段代码。详见 [tools/README.md](./tools/README.md)。
