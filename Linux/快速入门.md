# find
find 是 Linux 中用于查找文件和目录的命令。`find [搜索路径] [查找条件] [操作]`
## -name

## -type d
只查找目录
## -maxdepth
限制搜索深度。maxdepth 是一个全局选项（global option），应该写在 -type、-name 等查找条件之前。

# --
-- 有两种常见用法，具体含义取决于后面有没有参数名称。
## 一、单独的 --：结束选项解析
假设文件名是 -test.txt。如果执行：`rm -test.txt`rm 可能把 -test.txt 当成命令选项，导致报错。`rm -- -test.txt`表示：后面的内容都当作普通参数，不再当作选项。

## --参数名：长选项
--extract = -x  
--gzip = -z  
--verbose = -v  
--file = -f  
--directory = -C

# chmod
chmod 是 Linux 中用于修改文件或目录权限的命令。change mode
## chmod u+x file
所有者增加执行权限
## chmod -R 755 /root/project
-R 表示 recursive（递归），会修改目录及其内部所有文件和子目录。

# chown
chown 是 Linux 中用于**修改文件或目录所有者（owner）和所属组（group）**的命令。change owner（修改所有者）

# sudo
sudo 用于以其他用户的身份执行命令，默认以 root（超级管理员）身份执行。
