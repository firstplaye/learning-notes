# --
-- 有两种常见用法，具体含义取决于后面有没有参数名称。
## 一、单独的 --：结束选项解析
假设文件名是 -test.txt。如果执行：`rm -test.txt`rm 可能把 -test.txt 当成命令选项，导致报错。`rm -- -test.txt`表示：后面的内容都当作普通参数，不再当作选项。

## --参数名：长选项
--extract = -x  
--gzip = -z  
--verbose = -v  
--file = -f  
--directory = -C

# 重定向
重定向就是改变命令的输入或输出位置。
## >

## >>

## <

## 2>
将错误信息写入文件，2>>	将错误信息追加到文件

# wc

# 常用文本工具

# echo
echo 用于在终端输出文字、变量或其他字符串，也经常配合重定向符号 >、>> 创建或修改文本文件。`echo [选项] [内容]`
```
echo "Hello"             # 输出文字
echo "$HOME"             # 输出变量
echo -n "Hello"          # 不换行
echo "Hello" > test.txt  # 覆盖写入文件
echo "Linux" >> test.txt # 追加写入文件
```

# PID 与 PPID
在 Linux 中，每运行一个程序，系统就会创建一个或多个进程（Process）。
PID（Process ID）：进程 ID，用来唯一标识某一时刻的一个进程。
PPID（Parent Process ID）：父进程 ID，表示是谁创建了这个进程。

# ps
ps 是 Process Status（进程状态） 的缩写，用于查看 Linux 系统中正在运行的进程。
`ps -ef`
-e：显示所有进程。  
-f：显示完整格式，包括 UID、PID、PPID 等。  

# 查看系统资源
## top
持续查看进程的 CPU、内存使用，按 q 退出
## free -h
查看系统内存和 swap；-h 使用易读单位
## df与du
df（Disk Free）：查看整个文件系统的磁盘容量、已用空间和剩余空间。  
du（Disk Usage）：查看文件或目录实际占用了多少磁盘空间。  

# systemd
systemd 是 Linux 中常见的系统和服务管理器，负责启动、停止、监控系统服务，以及管理服务之间的依赖关系。journalctl → 查看日志的工具

# ip addr 和 ip route
ip addr：查看网卡、IP 地址、子网信息。  
ip route：查看路由表，了解数据包应该从哪个网卡、经过哪个网关发送。  

# ping -c 3 127.0.0.1
ping 发出 ICMP 探测，-c 3 只发三次；能收到回应说明这条探测有响应，但不代表 8080 端口或 HTTP 服务正常。

# ss -lnt与ss -lntp
ss（Socket Statistics）用于查看 Linux 的网络连接、端口监听情况及相关进程。
ss -lnt：查看正在监听的 TCP 端口。  
ss -lntp：除了端口，还显示占用端口的进程信息。  

# scp
scp（Secure Copy）用于通过 SSH 加密连接，在本地电脑和远程服务器之间复制文件或目录。`scp [选项] 源路径 目标路径`例如：scp app.jar root@192.168.1.100:/opt/myapp/
