# 1.什么是插槽
Props适合传数据，插槽适合让父组件提供一段模板内容。 
## 1. 插槽后备内容
插槽后备内容 = 插槽没有收到父组件内容时使用的默认内容。  
子组件 
```
<script setup>
defineProps({
  type: {
    type: String,
    default: 'button'
  }
})
</script>

<template>
  <button :type="type" class="base-button">
    <slot>确定</slot>
  </button>
</template>

<style scoped>
.base-button {
  padding: 8px 16px;
  margin: 5px;
  border: 1px solid #999;
  border-radius: 4px;
  background: white;
  cursor: pointer;
}

.base-button:hover {
  background: #f0f0f0;
}
</style>
```
父组件
```
<script setup>
import BaseButton from './components/BaseButton.vue'
</script>

<template>
  <main class="page">
    <h1>插槽后备内容示例</h1>

    <section>
      <h2>1. 没有传入插槽内容</h2>

      <BaseButton />
    </section>

    <section>
      <h2>2. 传入插槽内容</h2>

      <BaseButton>
        保存任务
      </BaseButton>

      <BaseButton>
        删除任务
      </BaseButton>

      <BaseButton>
        下一步
      </BaseButton>
    </section>

    <section>
      <h2>3. 传入其他 HTML 内容</h2>

      <BaseButton>
        <strong>重要操作</strong>
      </BaseButton>
    </section>
  </main>
</template>

<style scoped>
.page {
  padding: 30px;
}

section {
  margin-bottom: 24px;
}

h1 {
  margin-bottom: 24px;
}

h2 {
  font-size: 18px;
}
</style>
```

## 2.具名插槽
在一个组件中包含多个插槽出口  
```
<!-- BaseCard.vue -->
<template>
  <section class="base-card">
    <header><slot name="title" /></header>
    <div><slot /></div>
    <footer><slot name="actions" /></footer>
  </section>
</template>
<BaseCard>
  <template #title>
    <h2>任务信息</h2>
  </template>

  <p>担当：田中</p>

  <template #actions>
    <button type="button">编辑</button>
  </template>
</BaseCard>
```

## 3.作用域插槽
子组件向插槽传递数据，父组件接收这些数据，并决定如何显示它们。  

### `useSlots()`让脚本或模板判断具名插槽是否存在。
