# 快速入门VUE
## 1.什么是vue
Vue是运行在浏览器中的前端用户界面框架。它建立在HTML、CSS和JavaScript之上。

## 2.Vue、Vite、Node.js和npm的关系
浏览器负责显示和运行页面，Vue 负责组织页面，Vite 负责开发和构建，Node.js 提供工具运行环境，npm 负责安装和管理工具。   
| 名称    | 是什么                  | 主要作用                           |
| ------- | ----------------------- | ---------------------------------- |
| Vue     | JavaScript 前端框架     | 开发网页界面、组件和交互           |
| Vite    | 前端开发工具 / 构建工具 | 启动开发服务器、处理模块、打包项目 |
| Node.js | JavaScript 运行环境     | 让 JavaScript 可以在浏览器之外运行 |
| npm     | 包管理器                | 安装、管理和运行项目依赖及脚本     |

```
Node.js
  ↓ 提供运行环境
npm
  ↓ 安装和管理工具
Vite
  ↓ 启动、处理、构建项目
Vue
  ↓
你开发的网页
```

## 3.沿着`index.html` → `main.js` → `App.vue`找到页面入口的流程
### 第一步`index.html`是浏览器最先加载的页面  
`<div id="app"></div>`这是一个挂载容器。  
`<script type="module" src="/src/main.js"></script>`加载并执行 `src/main.js`这个JavaScript模块。 
### 第二步`main.js`应用的启动入口
#### 1.`import { createApp } from 'vue'`createApp是Vue提供的函数，用来创建Vue应用实例。
#### 2.`import App from './App.vue'把App.vue这个Vue组件导入进来，并命名为App。
#### 3.`createApp(App).mount('#app')`使用App创建Vue应用,找到HTML中`id="app"`的元素,把Vue 应用挂载到这个元素上。
### 第三步`App.vue`：根组件，页面内容从这里开始
流程图如下：
```
① 浏览器访问页面
        ↓
② 加载 index.html
        ↓
③ 找到 <script src="/src/main.js">
        ↓
④ 执行 main.js
        ↓
⑤ import App from './App.vue'
        ↓
⑥ createApp(App)
        ↓
⑦ mount('#app')
        ↓
⑧ App.vue 的 template 渲染到 <div id="app">
        ↓
⑨ 浏览器显示「你好，Vue！」
```

## 4.vue的特点是啥
### (1)声明式渲染（Declarative Rendering）：告诉 Vue“页面应该是什么样子”，而不是自己一步步操作DOM。
在JavaScript当数据发生变化时，需要自己修改 DOM。在vue中不用一直操作dom元素。  

#### vue
```js
<script setup>
import { ref } from "vue";
const count = ref(0);
</script>

<template>
  <p>{{ count }}</p>
  <!-- 当值发生改变时不需要添加其他dom语句，会自动变化 -->
  <button @click="count++">+1</button>
</template>
```

### (2)响应式（Reactivity）：数据发生变化时，相关的页面会自动更新。
```js
<script setup>
import { ref } from "vue";

const message = ref("你好");
</script>

<template>
  <p>{{ message }}</p>

  <button @click="message = 'Hello Vue!'">
    修改文字
  </button>
</template>
```

### (3)组件化（Component-Based）:Vue 把页面拆分成多个可复用的组件。
例如一个网站：
```
App.vue
├── Header.vue
├── Sidebar.vue
├── Home.vue
├── LoginForm.vue
└── Footer.vue
```
