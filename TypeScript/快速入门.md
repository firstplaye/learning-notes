# 一、TypeScript 简介
1.TypeScript 是 JavaScript 的超集  
2.TS 负责检查，JS 负责运行；有错误时是否生成 JS，还取决于编译选项。  

# 二、基本类型
1.自动类型判断  
当对变量的声明和赋值是同时进行的，TS 编译器会自动判断变量的类型，所以如果你的变量的声明和赋值时同时进行的，可以省略掉类型声明。  
```js
  let count = 2;
  count = "two";
  console.log(count); // 2
```
这里编译后输出`Type 'string' is not assignable to type 'number'.`效果等同于`let count: number = 2;`  

2.any和unknown的区别
`any`：放弃类型检查，想怎么用就怎么用。  
`unknown`:暂时不知道类型，使用前必须先确认类型。  
```js
let value : unknown = "xiaoming"; 
  function printLength(value: unknown) {
  // 此时：
  // value: unknown

  if (typeof value === "string") {
    // 此时：
    // value: string

    console.log(value.length); // 合法
  }

  // 离开 if 后：
  // value 又可能是任意类型
}
printLength(value);//8
```

3.类型断言和可选属性  
类型断言（Type Assertion），它只影响 TypeScript 编译器的判断，不会在运行时把字符串转换成数字。  
`typeof`是 JavaScript 运行时操作。
需要把字符串转数字时使用 Number()，不要写 as number。
类型断言和可选属性都需要判断后再使用
```js
  let value : unknown = "xiaoming"; 
  let test = value as number;
  console.log(test + 1);//"xiaoming1"
  console.log(typeof test);//String
  console.log(test);//xiaoming
```

4.数组与元组  
普通数组通常描述“元素是什么类型”；元组描述“每个位置分别是什么类型，以及有几个位置”。  
```js
  let user: [string, number] = ["小明", 20]; // 正确
  let user: [string, number] = [20, "小明"];// 报错
  let point: [number, number] = [100, 200];
  point= [100, 200, 300];// 报错
```

5.对象类型和类型别名  
对象值和对象类型都有花括号  
```js
  const employee: {
  employeeNumber: string;
  name: string;
  remainingLeaveDays: number;
} = {
  employeeNumber: "EMP-001",
  name: "田中",
  remainingLeaveDays: 12,
};

console.log(employee.name);               // 田中
console.log(employee.remainingLeaveDays); // 12
```

定义并使用类型别名  
```js
  type Employee = {
  readonly employeeNumber: string;//默认是浅层限制
  readonly profile?: {
    displayName: string;
  };
  name: string;
  nickname?: string;//可以赋值也可以不赋值，不赋值的情况下就不存在
};

const employeeA: Employee = {
  employeeNumber: "EMP-001",
  name: "田中",
  profile: {
    displayName: "田中",
  },
};

const employeeB: Employee = {
  employeeNumber: "EMP-002",
  name: "佐藤",
  nickname: "さとうさん",
};

console.log(employeeA.nickname); // undefined
if (employeeA.profile) {
  employeeA.profile.displayName = "tanaka";
}
if (employeeA.profile) {
  console.log(employeeA.profile.displayName);
}
console.log(employeeB.nickname); // さとうさん
```
