# react是什么？
React 是 Facebook 在 2011 年开发的插件 JavaScript 库。

# 什么是虚拟 DOM？
React 的虚拟 DOM（Virtual DOM）机制:React 不会每次状态变化都直接操作真实 DOM，而是先在 JavaScript 中生成一份“新的 UI 描述”，再和之前的 UI 描述比较，最后只把真正变化的部分更新到真实 DOM。

# react组件
React 的 UI 主要由一个个可组合的组件构成，页面本身也是组件组合出来的。
**React 组件是常规的 JavaScript 函数，但 组件的名称必须以大写字母开头，否则它们将无法运行！**
```
export default function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/MK3eW3Am.jpg"
      alt="Katherine Johnson"
    />
  );
}
```
**没有括号包裹的话，任何在 return 下一行的代码都 将被忽略！**

# JSX是什么
JSX 是 JavaScript 语法扩展，可以让你在 JavaScript 文件中书写类似 HTML 的标签。

# 为什么多个 JSX 标签需要被一个父元素包裹？ 
JSX 虽然看起来很像 HTML，但在底层其实被转化为了 JavaScript 对象，你不能在一个函数中返回多个对象，除非用一个数组把他们包装起来。这就是为什么多个 JSX 标签必须要用一个父元素或者 Fragment 来包裹。

## JSX 引号内的值会作为字符串传递给属性。大括号让你可以将 JavaScript 的逻辑和变量带入到标签中。
{{ 和 }} 并不是什么特殊的语法：它只是包在 JSX 大括号内的 JavaScript 对象。

# React 组件使用 props 来互相通信
props 是 不可变的。。当一个组件需要改变它的 props（例如，响应用户交互或新数据）时，它不得不“请求”它的父组件传递 不同的 props —— 一个新对象！它的旧 props 将被丢弃，最终 JavaScript 引擎将回收它们占用的内存。

```
  if (isPacked) {

```

# react中如何渲染列表
使用 map() 把数组转换成组件数组。filter() 筛选需要渲染的组件。
**直接放在 map() 方法里的 JSX 元素一般都需要指定 key 值！**
```
import { people } from './data.js';
import { getImageUrl } from './utils.js';

export default function List() {
  const chemists = people.filter(person =>
    person.profession === '化学家'
  );
  const listItems = chemists.map(person =>
    <li key={person.id}>
      <img
        src={getImageUrl(person)}
        alt={person.name}
      />
      <p>
        <b>{person.name}:</b>
        {' ' + person.profession + ' '}
        因{person.accomplishment}而闻名世界
      </p>
    </li>
  );
  return <ul>{listItems}</ul>;
}
```
# 纯函数是什么
只负责自己的任务。它不会更改在该函数调用前就已存在的对象或变量。  
输入相同，则输出相同。给定相同的输入，纯函数应总是返回相同的结果。  
## 副作用：（不符合）预期的后果 
React 的渲染过程必须自始至终是纯粹的。
```
let guest = 0;

function Cup() {
  // Bad：正在更改预先存在的变量！
  guest = guest + 1;
  return <h2>Tea cup for guest #{guest}</h2>;
}

export default function TeaSet() {
  return (
    <>
      <Cup />//2
      <Cup />//4
      <Cup />//6
    </>
  );
}
```
