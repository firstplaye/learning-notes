# 5.break 和 continue
break:主要用在循环语句或者 switch 语句中，表示跳出此循环，然后继续执行该循环下的语句。
continue:continue 也同样是应用在循环控制结构中，主要是让程序跳出当次循环，进而进入下一次循环的迭代。

# 6.成员变量和局部变量的区别
成员变量:类中，方法外,当前对象内部都可以使用,有默认值,随对象创建而存在，随对象回收而结束。  
局部变量:方法、构造方法或代码块中,只在定义它的代码块内部使用,没有默认值，使用前必须赋值,方法或代码块执行时创建，结束后失效。

# 7.方法重载
方法重载是同一个类中方法名相同，但参数列表不同。参数个数不同，参数类型不同，参数顺序不同。只改变返回值类型，不构成重载。
```
public class EmployeeFinder {

    public String findEmployee(Long id) {
        return "find by id";
    }

    public String findEmployee(String email) {
        return "find by email";
    }
}
```

# 8.构造方法是什么
构造方法是在 new 对象时自动执行的方法。方法名必须和类名相同,没有返回值类型,创建对象时自动调用。
## 1.默认构造方法
如果类中没有写任何构造方法，Java 会自动提供无参构造方法。
## 2.构造方法的特点
1. 方法名必须与类名相同  
2. 没有返回值类型  
3. 创建对象时自动调用   
4. 可以重载  
5. 可以有参数，也可以没有参数  
6. 不能被继承，也不能被重写

```
子类方法返回值类型必须和父类方法返回值类型相同，或者是父类返回值类型的子类。

private 方法不能被重写，因为子类无法继承父类的 private 方法。
final 方法不能被重写。
```

# 12.多态
多态是指父类引用可以指向子类对象。
```
public class PolymorphismDemo {
    public static void main(String[] args) {
        Employee employee = new FullTimeEmployee("Tanaka");
        System.out.println(employee.getEmployeeType()); // 输出：正式员工
    }
}
```

## 1.多态的作用
让代码依赖“共同的规则”，而不是依赖具体的对象。  
例如：
```
static void makeSound(Animal animal) {
    animal.speak();
}
```
现在不管传进去的是：
```
makeSound(new Dog());
makeSound(new Cat());
```
都可以。
以后增加：
```
class Bird extends Animal {
    @Override
    void speak() {
        System.out.println("啾啾");
    }
}
```
原来的：`makeSound()`完全不用修改。直接：`makeSound(new Bird())`;

## 2.向上转型和向下转型
### 1.向上转型
向上转型是把子类对象赋值给父类引用。向上转型后，可以调用父类中声明的方法。如果子类重写了该方法，运行时会执行子类版本。
```
Employee employee = new FullTimeEmployee("Tanaka");
```
### 2.向下转型
向下转型是把父类引用转换回子类类型。
```
Employee employee = new FullTimeEmployee("Tanaka");

if (employee instanceof FullTimeEmployee fullTimeEmployee) {
    System.out.println(fullTimeEmployee.getEmployeeType()); // 输出：正式员工
}
```
向下转型必须先判断真实对象类型。否则可能出现 ClassCastException。  
错误示例：
```
Employee employee = new ContractEmployee("Suzuki");
FullTimeEmployee fullTimeEmployee = (FullTimeEmployee) employee; // 运行时异常
```
employee 的真实对象是 ContractEmployee，不能强制转换成 FullTimeEmployee。

## 3.多态中的方法和成员变量
多态调用成员方法时，看运行时真实对象。成员变量不按多态处理，成员变量看引用类型。

# 13.static 是什么
static 表示成员属于类本身，而不是属于某一个对象。普通成员变量属于对象，每个对象各有一份。静态变量属于类，所有对象共享同一份。static 方法可以通过类名直接调用，不需要先创建对象。静态方法中不能直接访问普通成员变量，因为普通成员变量必须依赖具体对象。

## 1.static 不能修饰普通类，static 可以修饰内部的嵌套类

## 2.静态内部类
静态内部类是使用 static 修饰的嵌套类，它属于外部类本身，而不是外部类的某个对象，它不依赖外部类对象。可以直接访问外部类的静态成员，不能直接访问外部类的实例成员。

## 3.static 代码块
static 代码块会在类第一次被使用时执行一次，常用于初始化静态数据。
```
public class EmployeeStatus {
    public static final String ACTIVE;

    static {
        ACTIVE = "ACTIVE";
        System.out.println("初始化员工状态");
    }

    public static void main(String[] args) {
        System.out.println(EmployeeStatus.ACTIVE); // 输出：ACTIVE
    }
}
```

# 25.Java 中如何处理异常？

在 Java 中，**异常处理（Exception Handling）** 是指程序在运行过程中出现错误或异常情况时，通过特定的机制捕获异常、处理异常，避免程序因为未处理的异常而意外终止。

Java 主要通过以下几个关键字处理异常：

| 关键字       | 作用                    |
| --------- | --------------------- |
| `try`     | 包含可能发生异常的代码           |
| `catch`   | 捕获并处理异常               |
| `finally` | 执行收尾操作，通常无论是否发生异常都会执行 |
| `throw`   | 主动抛出一个异常对象            |
| `throws`  | 声明方法可能抛出的异常           |

---

## 一、使用 try-catch 捕获异常

这是 Java 中最常见的异常处理方式。

### 示例

```java
public class Main {
    public static void main(String[] args) {
        try {
            int result = 10 / 0;
            System.out.println(result);
        } catch (ArithmeticException e) {
            System.out.println("发生了算术异常：" + e.getMessage());
        }

        System.out.println("程序继续执行");
    }
}
```

### 执行结果

```text
发生了算术异常：/ by zero
程序继续执行
```

### 执行流程

1. 程序进入 `try` 代码块。
2. 执行 `10 / 0` 时发生 `ArithmeticException`。
3. 程序跳过 `try` 中剩余的代码，进入匹配的 `catch`。
4. 执行异常处理代码。
5. 继续执行 `catch` 后面的代码。

**注意：** 如果没有匹配的 `catch`，异常会继续向上层方法传播。

---

## 二、使用多个 catch 处理不同异常

一个 `try` 可以对应多个 `catch`，分别处理不同类型的异常。

### 示例

```java
try {
    int[] arr = {1, 2, 3};
    System.out.println(arr[5]);
} catch (ArithmeticException e) {
    System.out.println("算术异常");
} catch (ArrayIndexOutOfBoundsException e) {
    System.out.println("数组下标越界");
} catch (Exception e) {
    System.out.println("其他异常");
}
```

### 执行结果

```text
数组下标越界
```

**注意：** 如果使用多个 `catch`，通常要把更具体的异常放在前面，把更通用的异常（如 `Exception`）放在后面。

---

## 三、使用 finally 执行收尾操作

`finally` 通常用于释放资源或执行清理操作，无论是否发生异常，通常都会执行。

### 示例

```java
try {
    int result = 10 / 0;
} catch (ArithmeticException e) {
    System.out.println("发生异常");
} finally {
    System.out.println("执行清理操作");
}
```

### 执行结果

```text
发生异常
执行清理操作
```

---

## 四、使用 throw 主动抛出异常

`throw` 用于在代码中主动抛出一个异常对象。

### 示例

```java
public class Main {
    public static void main(String[] args) {
        int age = 15;

        if (age < 18) {
            throw new IllegalArgumentException("年龄必须满18岁");
        }
    }
}
```

这里会主动抛出 `IllegalArgumentException`，程序如果没有捕获该异常，就会终止当前执行流程并显示异常信息。

---

## 五、使用 throws 声明异常

`throws` 用于在方法声明中说明该方法可能抛出的异常，让调用者知道需要处理哪些异常。

### 示例

```java
import java.io.IOException;

public class Main {

    public static void readFile() throws IOException {
        throw new IOException("文件读取失败");
    }

    public static void main(String[] args) {
        try {
            readFile();
        } catch (IOException e) {
            System.out.println(e.getMessage());
        }
    }
}
```

### 关键代码解释

* `throws IOException`：声明方法可能抛出 `IOException`。
* `throw new IOException(...)`：真正创建并抛出异常。
* `catch (IOException e)`：捕获并处理异常。

---

## 六、Java 异常处理的整体流程

1. 执行 `try` 代码块。
2. 判断是否发生异常：

   * **没有异常：** 执行 `try` 中的代码，然后执行 `finally`（如果存在）。
   * **发生异常：** 跳过 `try` 中剩余代码，进入匹配的 `catch` 处理异常，然后执行 `finally`（如果存在）。
3. 执行后续代码。

---

## 七、总结

| 关键字       | 记忆方法        |
| --------- | ----------- |
| `try`     | 尝试执行可能出错的代码 |
| `catch`   | 捕获并处理异常     |
| `finally` | 执行收尾操作      |
| `throw`   | 主动抛出异常      |
| `throws`  | 声明可能抛出的异常   |

**一句话记忆：** `try-catch` 负责捕获异常，`finally` 负责收尾，`throw` 负责抛出异常，`throws` 负责声明异常。
