# 1.变量
变量必须先声明再使用,类型一旦确定，不可存储其他类型数据,定义时可不赋值，但使用前必须赋值,同一作用域内不可重复定义
变量的值可被重新赋值,变量以小驼峰的形式命名(小写字母开头，换单词首字母大写)，例如:userName, totalCount。

## 2.引用数据类型

# 3.变量作用域
变量的作用域是指变量自定义的地方起，可以使用的有效范围。 在程序中不同的地方定义的变量具有不同的作用域。 一般情况下，在本程序块（即以大括号“{}”括起的程序段）内定义的变量在本程序块内有效。

# 4.常量
既然有变量，那就有与之相对的常量（也就是值是固定的，不能再变）。通常我们把 Java 中用 final 关键字所修饰的成员变量叫做常量，它的值一旦给定就无法再进行改变！

# 5.break 和 continue
break:主要用在循环语句或者 switch 语句中，表示跳出此循环，然后继续执行该循环下的语句。
continue:continue 也同样是应用在循环控制结构中，主要是让程序跳出当次循环，进而进入下一次循环的迭代。

# 6.成员变量和局部变量的区别
成员变量:类中，方法外,当前对象内部都可以使用,有默认值,随对象创建而存在，随对象回收而结束。  
局部变量:方法、构造方法或代码块中,只在定义它的代码块内部使用,没有默认值，使用前必须赋值,方法或代码块执行时创建，结束后失效。

# 7.方法重载
方法重载是同一个类中方法名相同，但参数列表不同。参数个数不同，参数类型不同，参数顺序不同。只改变返回值类型，不构成重载。
```
public class EmployeeFinder {

    public String findEmployee(Long id) {
        return "find by id";
    }

    public String findEmployee(String email) {
        return "find by email";
    }
}
```

# 8.构造方法是什么
构造方法是在 new 对象时自动执行的方法。方法名必须和类名相同,没有返回值类型,创建对象时自动调用。
## 1.默认构造方法
如果类中没有写任何构造方法，Java 会自动提供无参构造方法。

# 11.为什么需要继承
当多个类有相同属性和方法时，可以把共同部分抽取到父类。

## 1.super
super 表示父类对象部分，常用于调用父类构造方法或父类方法。

## 2.方法重写
方法重写是子类重新定义父类已有的方法。只发生在子父类，接口，抽象类中。

## 3.重写成立的条件
```
子类和父类之间必须有继承关系。
子类方法名必须和父类方法名相同。
子类方法参数列表必须和父类方法参数列表相同。
子类方法返回值类型必须和父类方法返回值类型相同，或者是父类返回值类型的子类。
子类方法访问权限不能比父类方法更严格。
private 方法不能被重写，因为子类无法继承父类的 private 方法。
final 方法不能被重写。
```

# 12.多态
多态是指父类引用可以指向子类对象。
```
public class PolymorphismDemo {
    public static void main(String[] args) {
        Employee employee = new FullTimeEmployee("Tanaka");
        System.out.println(employee.getEmployeeType()); // 输出：正式员工
    }
}
```

## 1.多态的作用
让代码依赖“共同的规则”，而不是依赖具体的对象。  
例如：
```
static void makeSound(Animal animal) {
    animal.speak();
}
```
现在不管传进去的是：
```
makeSound(new Dog());
makeSound(new Cat());
```
都可以。
以后增加：
```
class Bird extends Animal {
    @Override
    void speak() {
        System.out.println("啾啾");
    }
}
```
原来的：`makeSound()`完全不用修改。直接：`makeSound(new Bird())`;

## 2.向上转型和向下转型
### 1.向上转型
向上转型是把子类对象赋值给父类引用。向上转型后，可以调用父类中声明的方法。如果子类重写了该方法，运行时会执行子类版本。
```
Employee employee = new FullTimeEmployee("Tanaka");
```
### 2.向下转型
向下转型是把父类引用转换回子类类型。
```
Employee employee = new FullTimeEmployee("Tanaka");

if (employee instanceof FullTimeEmployee fullTimeEmployee) {
    System.out.println(fullTimeEmployee.getEmployeeType()); // 输出：正式员工
}
```
向下转型必须先判断真实对象类型。否则可能出现 ClassCastException。  
错误示例：
```
Employee employee = new ContractEmployee("Suzuki");
FullTimeEmployee fullTimeEmployee = (FullTimeEmployee) employee; // 运行时异常
```
employee 的真实对象是 ContractEmployee，不能强制转换成 FullTimeEmployee。
