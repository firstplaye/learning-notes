# 1.什么是html？它有什么特点？
HTML（HyperText Markup Language），即超文本标记语言，是用来描述网页结构和内容的标记语言。  
HTML 使用标签来组织内容，通常由开始标签、内容和结束标签组成。HTML 元素可以相互嵌套，形成树状结构，也就是DOM树。

# 2.HTML元素的显示性质
通常分为三类：  
## 1.块级元素（Block）独占一行  
默认从新的一行开始显示。默认占据父元素可用的整行宽度。可以设置 width、height、margin、padding 等。多个块级元素通常从上到下排列。常见元素`<div>、<p>、<h1>～<h6>、<ul>、<ol>、<li>、<section>、<header> `
## 2.行内元素（Inline）不独占一行  
不会强制换行，多个元素可以在同一行排列。宽度和高度通常由内容决定。width 和 height 通常不能直接改变其显示尺寸。水平方向的 padding 和 margin 可以生效；垂直方向的外边距通常不影响行布局。常见元素`<span>、<a>、<strong>、<em>、<b>、<i>、<label>`。  
行内块元素（Inline-block）同行排列 + 可设置宽高  
不独占一行，可以与其他行内元素或行内块元素并排显示。可以设置 width 和 height。可以设置内边距 padding、外边距 margin。多个元素可以横向排列，空间不足时换行。`<img>、<input>、<button> `在常见默认样式下具有类似行内块的布局表现。  

# 3.什么标签可以实现页面内跳转  
HTML 使用<a>实现页面内跳转，通常通过 href 属性指定目标位置的 id。
```
<!-- 点击后跳转到 id="content" 的位置 -->
<a href="#content">跳转到内容区域</a>

<!-- 页面中的目标位置 -->
<h2 id="content">内容区域</h2>
```

# 4.HTML 文本格式化标签有哪些？
HTML 文本格式化标签主要用于设置文字的强调程度、语义含义或视觉表现。  
| 标签 | 作用 | 显示效果 |
|---|---|---|
| `<b>` | 让文字加粗，不表示特别重要 | **加粗文字** |
| `<strong>` | 表示内容具有重要性，通常加粗 | **重要文字** |
| `<i>` | 表示不同语气或专业术语，通常斜体 | *斜体文字* |
| `<em>` | 表示强调，通常斜体 | *强调文字* |
| `<u>` | 标记文字，通常显示下划线 | <u>下划线文字</u> |
| `<s>` | 表示内容已不再准确或有效，通常显示删除线 | ~~删除线文字~~ |
| `<del>` | 表示删除的内容 | ~~已删除文字~~ |
| `<ins>` | 表示新增的内容，通常显示下划线 | <u>新增文字</u> |
| `<mark>` | 标记或突出显示文字，通常带有背景色 | <mark>高亮文字</mark> |
| `<small>` | 表示小字或附属说明 | <small>小号文字</small> |
| `<sub>` | 下标 | H<sub>2</sub>O |
| `<sup>` | 上标 | x<sup>2</sup> |

# 5.form 的常用属性
action:	提交目标的 URL 或文件路径  
method: get、post指定提交方式
autocomplete:on、off提示浏览器是否可以自动填充

# 6.get和post的区别
get:数据通常出现在目标地址的查询部分，适合观察提交结果。  
post:数据不会放在地址的查询部分，通常需要服务器接收。

# 7.什么是语义化
**语义化（Semantic）**：使用能够表达内容含义的 HTML 标签，让浏览器、开发者和辅助技术能够理解网页中不同内容的作用。
