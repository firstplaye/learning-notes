# 1.为什么需要数据库  
程序运行时，数据通常保存在内存中。程序关闭后，内存中的数据会消失。数据库用于长期保存数据，这个过程叫持久化。

# 2.SQL是什么
SQL 是 Structured Query Language 的缩写，中文叫结构化查询语言。SQL 用于操作关系型数据库。

# 3.SQL分类
DDL（Data Definition Language）数据定义语言，用来定义数据库对象：数据库、表、列等。DDL 简单理解就是用来操作数据库和表的。CREATE、ALTER、DROP、TRUNCATE  
DML（Data Manipulation Language）数据操作语言，用来对数据库中表的数据进行增删改DML 简单理解就对表中数据进行增删改。INSERT、UPDATE、DELETE  
DQL（Data Query Language）数据查询语言，用来查询数据库中表的记录（数据）。DQL简单理解就是对数据进行查询操作，从数据库表中查询到我们想要的数据。SELECT  
DCL（Data Control Language）数据控制语言，用来定义数据库的访问权限和安全级别及创建用户 

# 4.四种数据库默认端口
Mysql:3306  
Oracle:1512  
PostgreSQL:5432  
SQL Server:1433  

# 5.创建数据库
MySQL,PostgreSQL,SQL Server都是`CREATE DATABASE training_db;`  
Oracle是
```
CREATE USER training_user IDENTIFIED BY password;  
GRANT CONNECT, RESOURCE TO training_user;
```
