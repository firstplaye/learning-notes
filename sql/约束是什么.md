# 1.约束是什么
约束用于限制表中数据的规则。

## 1.三种常见约束写法
有名称的约束:`CONSTRAINT 约束名 约束类型 (列名)`
无名称的约束:如`id BIGINT PRIMARY KEY`
添加联合约束：`CONSTRAINT 约束名 UNIQUE (列名1, 列名2)`

## 2.表已存在时，添加约束的方法
添加主键:  
`ALTER TABLE 表名 ADD CONSTRAINT 主键约束名 PRIMARY KEY (主键列名);`
添加唯一约束:  
`ALTER TABLE 表名 ADD CONSTRAINT 唯一约束名 UNIQUE (列名);`
添加检查约束:  
`ALTER TABLE 表名 ADD CONSTRAINT 检查约束名 CHECK (检查条件);`
添加外键约束:(子表必须引用父表中已存在的值)  
`ALTER TABLE 子表名 ADD CONSTRAINT 外键约束名 FOREIGN KEY (子表列名) REFERENCES 父表名(父表列名);`
添加非空约束:  
Mysql:    
`ALTER TABLE 表名 MODIFY 列名 数据类型 NOT NULL;`
Oracle:    
`ALTER TABLE 表名 MODIFY (列名 数据类型 NOT NULL);`
PostgreSQL:    
`ALTER TABLE 表名 ALTER COLUMN 列名 SET NOT NULL;`
SQL Server:  	
`ALTER TABLE 表名 ALTER COLUMN 列名 数据类型 NOT NULL;`
添加默认值:  
MySQL:  
`ALTER TABLE 表名 ALTER 列名 SET DEFAULT 默认值;`
Oracle:  
`ALTER TABLE 表名 MODIFY (列名 DEFAULT 默认值);`
PostgreSQL:      
`ALTER TABLE 表名 ALTER COLUMN 列名 SET DEFAULT 默认值;`
SQL Server:    
`ALTER TABLE 表名 ADD CONSTRAINT 默认值约束名 DEFAULT 默认值 FOR 列名;`

## 3.删除约束
删除主键:
mysql:`ALTER TABLE 表名 DROP PRIMARY KEY;`  
其他三个:`ALTER TABLE 表名 DROP CONSTRAINT 主键约束名;`

删除唯一约束:
MySQL:`ALTER TABLE 表名 DROP INDEX 唯一索引名;`
其他三个:`ALTER TABLE 表名 DROP CONSTRAINT 唯一约束名;`

删除检查约束:
MySQL:`ALTER TABLE 表名 DROP CHECK 检查约束名;`
其他三个:`ALTER TABLE 表名 DROP CONSTRAINT 检查约束名;`

删除外键约束:
Mysql:`ALTER TABLE 表名 DROP FOREIGN KEY 外键约束名;`
其他三个:`ALTER TABLE 表名 DROP CONSTRAINT 外键约束名;`

删除非空约束:
Mysql:`ALTER TABLE 表名 MODIFY 列名 数据类型 NULL;`
Oracle:`ALTER TABLE 表名 MODIFY (列名 数据类型 NULL);`
PostgreSQL:`ALTER TABLE 表名 ALTER COLUMN 列名 DROP NOT NULL;`
SQL Server:`ALTER TABLE 表名 ALTER COLUMN 列名 数据类型 NULL;`

删除默认值:
Mysql:`ALTER TABLE 表名 ALTER 列名 DROP DEFAULT;`
Oracle:`ALTER TABLE 表名 MODIFY (列名 DEFAULT NULL);`
PostgreSQL:`ALTER TABLE 表名 ALTER COLUMN 列名 DROP DEFAULT;`
SQL Server:`ALTER TABLE 表名 DROP CONSTRAINT 默认值约束名;`

## 4.修改约束
多数数据库不能直接“修改约束内容”。常见做法是：先删除旧约束，再添加新约束。

## 5.查看约束
MySQL：`SHOW CREATE TABLE employees;`
Oracle：`SELECT constraint_name, constraint_type FROM user_constraints WHERE table_name = 'EMPLOYEES';`
PostgreSQL：`SELECT constraint_name, constraint_type FROM information_schema.table_constraints WHERE table_name = 'employees';`
SQL Server:`SELECT name, type_desc FROM sys.objects WHERE parent_object_id = OBJECT_ID('employees');`
